# Responsive Landing Page

A modern and fully responsive landing page built using **HTML5, CSS3, and Bootstrap**. The project focuses on responsive layouts, clean UI design, and a consistent user experience across different screen sizes.

## Features

* Fully responsive design for desktop, tablet, and mobile devices
* Modern and clean user interface
* Responsive navigation
* Structured landing page sections
* Responsive layouts using Flexbox and CSS Grid
* Bootstrap-based responsive components
* Cross-browser compatible design
* Mobile-friendly layout

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* Flexbox
* CSS Grid
